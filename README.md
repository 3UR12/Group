## Proyecto

Desarrollamos tres mini-compiladores académicos y sus evidencias técnicas como parte del portal colaborativo de la asignatura.

Nuestro trabajo cubre reconocimiento de instrucciones, análisis léxico, validación sintáctica, generación de código y pruebas con entradas válidas e inválidas.

## Mini-compiladores

| Módulo | Entrada principal | Resultado |
|---|---|---|
| Hola Mundo | `IMPRIMIR "Hola Mundo"` | Código C# y ejecución |
| Estructuras IF | `SI edad >= 18 ENTONCES` | Código C# con `if` |
| Lenguaje para formularios | Instrucciones de formulario | Aplicación Windows Forms |

## Flujo de trabajo

```text
Código fuente
    ↓
Análisis léxico
    ↓
Análisis sintáctico
    ↓
Generación de código
    ↓
Compilación y ejecución
    ↓
Resultado y evidencia
```
