# Portal del Grupo 1

Aquí reunimos las páginas técnicas de nuestros tres mini-compiladores para integrarlas con el portal general de la clase.

Cada módulo presenta:

- Lenguaje fuente.
- Tokens reconocidos.
- Análisis sintáctico.
- Código generado.
- Resultado de ejecución.
- Caso válido.
- Caso inválido con mensaje controlado.

La navegación y la presentación mantienen una estructura común entre los tres módulos.
