# Convenciones de trabajo

## Ramas

Usamos nombres cortos y descriptivos en español.

```text
grupo-01-desarrollo
hola-mundo
estructuras-if
formularios
portal
```

## Commits

Los mensajes indican directamente el cambio realizado.

```text
Agrega analizador léxico de Hola Mundo
Corrige validación de cadenas
Integra generación de código C#
Agrega pruebas de estructuras IF
Documenta lenguaje para formularios
```

## Pull Requests

Cada integración incluye un resumen breve, las pruebas realizadas y los archivos principales modificados.

## Código

- Nombres claros y consistentes.
- Archivos separados por responsabilidad.
- Texto visible para el usuario en español.
- Mensajes de error directos y controlados.
- Sin archivos generados por Visual Studio dentro del repositorio.
