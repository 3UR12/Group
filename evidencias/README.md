# Evidencias

Organizamos aquí las pruebas técnicas de nuestros mini-compiladores.

```text
evidencias/
├── hola-mundo/
├── estructuras-if/
└── formularios/
```

En cada módulo registramos la entrada utilizada, los tokens obtenidos, el código generado, el resultado de ejecución y al menos un caso inválido con mensaje controlado.
